    创建 Fine-grained personal access token，选择 Only select repositories，只选 math-ai-notes 和 math-ai-journal 两个仓库，授予 Contents 的 Read and write 权限，并设置合适的到期时间。

    在 GitHub 创建授权令牌 ↗
  2. 在当前页面连接

    令牌只在当前页面内存中使用，刷新或关闭页面后需重新连接。只在这个输入框填写。

保存与发布

保存私有稿会直接写入你的私有仓库，手机和电脑连接同一账户即可取回。发布会把选定文章复制到公开网站仓库；公开仓库历史可能保留此前发布过的内容。

文库备份

JSON 备份包含私有文稿和图片。导入只合并到私有文库，不会自动发布。
